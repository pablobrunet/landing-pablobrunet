# Reforma constitucional de Santa Fe

Fotos de las participaciones presentando el proyecto sobre inteligencia
artificial y pymes.

- Formato apaisado (16:9 o similar); se recortan al centro.
- Ancho mínimo 1200 px.
- Nombres con guiones y sin acentos: `reforma-01.jpg`, `reforma-02.jpg`…

Después completá `src/data/sobreMi.ts` → `reforma.fotos`.
